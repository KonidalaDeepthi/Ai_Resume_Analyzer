# AI Resume Skill Matcher

An AI-powered web application that analyzes resumes and matches them with suitable job roles based on skills.  
Built as a hackathon project using Django.
it helps for future students 

---

##  Features

- Resume upload (PDF) or text paste
- Automatic skill extraction using NLP
- Job role matching with skill match percentage
- Missing skill identification
- Resume strength score
- Interview question recommendations
- Learning suggestions for missing skills
- Clean and responsive UI

---

##  Job Roles Supported

- Software Developer  
- Data Analyst  
- Machine Learning Engineer  

---

## Tech Stack

- **Backend:** Python, Django  
- **Frontend:** HTML, CSS, Bootstrap  
- **Database:** SQLite  
- **NLP:** Basic text processing
